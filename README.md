🧪 Test Project – Online Booking System

This project was created as a test to evaluate the functionality and reliability of an online booking system.
It’s designed to simulate a real-world environment by integrating the system into an original website and using real appointments for testing purposes.

🛠️ Tech Stack

Next.js – Frontend framework for building a fast and responsive user interface
Firebase – Used for authentication and real-time database
Node.js – Backend logic and API handling

🚀 Project Goal

The main goal of this project is to test the complete booking workflow — from creating and managing appointments to sending notifications — ensuring smooth operation and scalability.
This setup allowed me to test the system’s performance and identify potential improvements before deploying it to production.
